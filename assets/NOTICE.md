# Asset sources

I copied the OpenCode logo, navigation artwork, and product icon from [OpenCode 2.2.1](https://github.com/anomalyco/opencode/tree/v2.2.1).
The OpenCode repository uses the MIT License.

| Asset | Source |
| --- | --- |
| Product icon | `packages/app/public/favicon.svg` |
| Logo paths | `services/www/public/assets/logo-dark.svg` |
| Navigation paths | `packages/ui/src/icons/catalog.ts` and `packages/ui/src/icons/icon/additional-icons.ts` |
| Color values | `packages/ui/src/theme/themes/oc-2.json` |
| Inter | `packages/app/public/assets/Inter.ttf` |

I rendered the standalone product mark on its original black background for the app icon.
I added padding around the same artwork for Android adaptive launcher masks.

I copied IBM Plex Mono Text from the [official IBM Plex repository](https://github.com/IBM/plex/blob/master/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Text.ttf).
The font files use the SIL Open Font License.
The `fonts` directory includes both font licenses.
